# Calculadora-Cient-fica
Calculadora científica responsiva feita com HTML, CSS e JavaScript puro para Programação para Web I. Inclui funções trigonométricas, logaritmos, raiz, potência, fatorial, alternância entre Graus (DEG) e Radianos (RAD), histórico e suporte a teclado.

Para essa entrega, eu quis criar algo diferente e útil no dia a dia, então montei uma calculadora científica funcional reunindo tudo em um arquivo index.html.
Comecei estruturando no HTML o visor — onde aparece o histórico da conta e o resultado principal — junto com a grade de botões. No CSS, deixei o layout simples, com tema escuro e botões bem espaçados para ficar confortável de usar tanto no celular quanto no computador.
Por fim, usei o JavaScript para dar vida aos botões e também aceitar o teclado físico. Além das operações básicas, coloquei funções científicas como seno, cosseno, tangente, raiz quadrada, potência e fatorial, junto com uma opção no topo para trocar entre graus e radianos na hora do cálculo.
